# keylens (placeholder)

This package is a placeholder so that `npx keylens` does not resolve to an unrelated package.

The Keylens keyboard navigation testing CLI is published as **`@progress/keylens`**:

```bash
npx @progress/keylens audit https://your-site.com
```

Or install it in your project:

```bash
npm install --save-dev @progress/keylens
npx playwright install chromium
npx keylens audit https://your-site.com
```

See the [install instructions](https://github.com/telerik/keylens#install).
